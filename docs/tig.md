# tig

## 設定内容

### 表示設定

* main-view: コミットID（12文字幅）、日付、作者、コミットタイトル、グラフ、参照を表示

## キーバインド

### GitHub連携

* `B` (main view) : コミットをGitHubで開く
* `B` (diff view) : コミットをGitHubで開く
* `B` (tree view) : ディレクトリをGitHubで開く
* `B` (blob view) : ファイルをGitHubで開く

### Git操作

* `R` (main view) : インタラクティブリベースを開始
* `R` (diff view) : インタラクティブリベースを開始
