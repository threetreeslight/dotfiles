# tmux

## 設定内容

### 基本設定

* 履歴制限: 30000行
* マウス操作: 有効
* コピーモード: viキーバインド
* アクティビティ監視: 有効
* ウィンドウ番号の再番号付け: 有効（ウィンドウを閉じたときに自動再番号付け）
* デフォルトコマンド: `reattach-to-user-namespace`（macOSのクリップボード連携用）

## キーバインド

### ペイン操作

* `h, j, k, l` : ペイン間を移動（vim風）
* `H, J, K, L` : ペインをリサイズ（繰り返し可能）
* `s` : ウィンドウを縦に分割
* `v` : ウィンドウを横に分割

### コピーモード

* `ctrl + b + [` : コピーモードに入る
* `v` : 選択開始
* `Enter` または `y` : コピーして終了（macOSのクリップボードにコピー）
* `C-v` : 矩形選択モード
* `[` : 選択開始
* `]` : 選択終了
* `Up/Down` : コマンド履歴を上下に移動（edit-mode-vi）

### その他

* `r` : 設定ファイルをリロード
* `ctrl + b + ]` : スクロールモード
* マウスホイール: コピーモードに入る
